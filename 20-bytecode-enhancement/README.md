## Инструментирование байт-кода
-   ```Bytecode Enhancement (Инструментирование байт-кода)``` (модификация скомпилированных .class файлов для добавления низкоуровневых оптимизаций) - выполняется через Maven (`hibernate-enhance-maven-plugin`) или Gradle плагин на этапе сборки
-   ```Lazy Loading скалярных полей (Lazy Property Fetching)``` (отложенная загрузка тяжелых полей без выноса во вторую таблицу) - поля типа `@Lob byte[] image` или `String description` не читаются из БД, пока к ним явно не обратятся
-   ```In-line Dirty Tracking (Отслеживание изменений без теневых копий)``` (колоссальная экономия оперативной памяти JVM) - плагин внедряет код отслеживания прямо в сеттеры классов; отпадает необходимость хранить второй массив-снапшот каждого объекта в L1 кэше
-   ```Bidirectional Association Management``` (автоматическая синхронизация обеих сторон связи в памяти) - вызов `order.setUser(user)` автоматически добавляет `order` в коллекцию `user.getOrders()`
-   ```Избавление от проблем CGLIB / ByteBuddy Runtime Proxies``` (прямой вызов методов без оверхеда динамических прокси) - повышает производительность вызовов методов сущностей при высокой нагрузке
