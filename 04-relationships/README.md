## Связи между сущностями
-   ```@OneToOne``` (связь «один к одному»: пользователь — профиль) - `@JoinColumn(name = "profile_id")` — указывает FK на стороне владельца; `mappedBy` — на обратной стороне
-   ```@OneToMany(mappedBy = "user")``` (связь «один ко многим»: пользователь — заказы) - `mappedBy` указывает поле в дочерней сущности; без `mappedBy` создаётся промежуточная таблица (нежелательно)
-   ```@ManyToOne``` (связь «многие к одному»: заказ — пользователь, владелец связи) - всегда является владеющей стороной (содержит FK); `@JoinColumn(name = "user_id")` — колонка внешнего ключа
-   ```@ManyToMany``` (связь «многие ко многим»: студенты — курсы) - `@JoinTable(name = "student_course", joinColumns = @JoinColumn(name = "student_id"), inverseJoinColumns = @JoinColumn(name = "course_id"))`
-   ```cascade = CascadeType.ALL``` (автоматическое распространение операций на связанные сущности) - `PERSIST`, `MERGE`, `REMOVE`, `REFRESH`, `DETACH`; `ALL` — все сразу; осторожно с `REMOVE` в `@ManyToMany`
-   ```orphanRemoval = true``` (автоматическое удаление дочерних записей при разрыве связи) - удаляет дочернюю сущность, если она убрана из коллекции родителя; работает с `@OneToMany`, `@OneToOne`
-   ```fetch = FetchType.LAZY``` (отложенная загрузка связанных сущностей до момента обращения) - по умолчанию для `@OneToMany`, `@ManyToMany`; загружает данные при первом доступе к коллекции
-   ```fetch = FetchType.EAGER``` (немедленная загрузка связанных сущностей вместе с родителем) - по умолчанию для `@ManyToOne`, `@OneToOne`; может вызвать N+1 проблему при загрузке коллекций
-   ```@JoinColumn(name = "user_id")``` (указание колонки внешнего ключа в таблице) - `nullable`, `unique`, `insertable`, `updatable` — дополнительные параметры
-   ```@OrderBy("createdAt DESC")``` (сортировка элементов коллекции при загрузке из БД) - применяется к `List`; добавляет `ORDER BY` в SQL запрос
-   ```@MapKey(name = "code")``` (использование поля сущности как ключа в Map-коллекции) - `Map<String, Country> countries` — ключ берётся из поля `code` сущности `Country`
