## Маппинг сущностей
-   ```@Entity``` (объявление класса как JPA-сущности, управляемой Hibernate) - класс должен иметь конструктор без аргументов; маппится на таблицу с именем класса по умолчанию
-   ```@Table(name = "users")``` (явное задание имени таблицы и её свойств) - `schema`, `catalog`, `uniqueConstraints`, `indexes` — дополнительные параметры
-   ```@Column(name = "user_name", nullable = false, length = 100)``` (тонкая настройка маппинга поля на колонку) - `unique`, `insertable`, `updatable`, `columnDefinition`, `precision`, `scale`
-   ```@Enumerated(EnumType.STRING)``` (сохранение enum-значений в БД в читаемом виде) - `STRING` — хранит имя константы; `ORDINAL` (по умолчанию) — хранит порядковый номер (хрупко при переупорядочивании)
-   ```@Temporal(TemporalType.TIMESTAMP)``` (маппинг Date/Calendar на конкретный SQL тип даты) - `DATE` — только дата; `TIME` — только время; `TIMESTAMP` — дата и время; для `LocalDate`/`LocalDateTime` не нужен
-   ```@Lob``` (хранение больших объёмов данных: текстов, файлов, изображений) - для `String` → `CLOB` (текст); для `byte[]` → `BLOB` (бинарные данные)
-   ```@Transient``` (исключение поля из маппинга на БД) - поле не сохраняется и не читается из БД; аналог ключевого слова `transient` в Java
-   ```@Access(AccessType.FIELD)``` (выбор стратегии доступа к полям: через поля или геттеры) - `FIELD` — Hibernate читает поля напрямую; `PROPERTY` — через getter/setter
-   ```@Embeddable / @Embedded``` (вынесение группы полей в переиспользуемый компонент) - `@Embeddable` на классе-компоненте (`Address`); `@Embedded` на поле сущности; колонки встраиваются в таблицу сущности
-   ```@AttributeOverride``` (переопределение имён колонок встраиваемого компонента) - используется когда один `@Embeddable` встраивается несколько раз в одну сущность
-   ```@Formula("(SELECT COUNT(*) FROM orders o WHERE o.user_id = id)")``` (вычисляемое поле через SQL без хранения в таблице) - read-only; вычисляется при каждом чтении сущности; не участвует в INSERT/UPDATE
-   ```@CreationTimestamp / @UpdateTimestamp``` (автоматическая установка дат создания и обновления) - Hibernate-специфичные аннотации; ставят текущее время при создании / каждом обновлении
