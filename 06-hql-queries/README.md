## HQL и JPQL запросы
-   ```HQL (Hibernate Query Language)``` (объектно-ориентированный диалект SQL, оперирующий классами и свойствами) - независим от СУБД; транслируется в нативный SQL через SQM парсер Hibernate 6
-   ```JOIN FETCH``` (жадная загрузка связанных коллекций или объектов одним SQL JOIN запросом) - `SELECT u FROM User u JOIN FETCH u.orders`; главный инструмент устранения проблемы N+1
-   ```Опасность JOIN FETCH с пагинацией (firstResult / maxResults)``` (предотвращение выборки всей таблицы в память JVM) - при пагинации коллекции Hibernate выводит предупреждение HHH000104 и выполняет пагинацию в оперативной памяти Java; решение: двухфазный запрос по ID
-   ```SELECT NEW com.example.UserDTO(...)``` (проекция результатов выборки напрямую в Java DTO или Record) - загружает только нужные колонки, не загружает сущности в Persistence Context, снижая расход RAM
-   ```Оконные функции (Window Functions) в Hibernate 6``` (выполнение аналитических SQL-функций прямо в HQL) - `ROW_NUMBER() OVER(PARTITION BY u.deptId ORDER BY u.salary DESC)`, `RANK()`, `DENSE_RANK()`
-   ```Common Table Expressions (CTE / WITH clause) в Hibernate 6``` (построение сложных и рекурсивных подзапросов в HQL) - нативная поддержка конструкции `WITH cte AS (...) SELECT ...`
-   ```Именованные параметры (:name)``` (безопасная передача аргументов с защитой от SQL Injection) - `query.setParameter("name", val)`; позиционные параметры `?1` также поддерживаются
-   ```@NamedQuery & @NamedNativeQuery``` (предварительно скомпилированные и валидируемые на этапе старта запросы) - объявляются над классами сущностей; синтаксические ошибки выявляются при запуске приложения
-   ```Массовые операции (Bulk UPDATE / DELETE)``` (выполнение прямых изменений в таблице без загрузки сущностей в память) - `UPDATE User u SET u.active = false WHERE u.lastLogin < :date`; обходит кэш L1, требует вызова `session.clear()`
-   ```HQL с нативными функциями СУБД (function())``` (вызов специфичных функций базы данных из HQL) - `SELECT function('jsonb_extract_path_text', u.data, 'email') FROM User u`
